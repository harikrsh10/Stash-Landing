Security & privacy

Built to be trusted with what you copy

Stash runs entirely on your machine. Here's exactly what that means.

Ordinary history never touches disk

What you copy lives in memory and clears the moment you quit. Only the clips you deliberately pin, and the prompts you save, are ever written down.

Nothing you copy ever leaves your device

Pinned clips and prompts are saved to one file on your own machine — never uploaded, never synced to a server.

Secrets never make it into history

API keys, JWTs, AWS credentials, 2FA codes and card numbers are detected and silently skipped before they're ever stored.

First run

From download to first paste, in about a minute

  1. 01

    Open the downloaded .dmg

    Double-click the file in your Downloads folder, then drag the Stash icon into Applications.

  2. 02

    Open Stash from Applications

    Double-click Stash to launch it. It appears in your menu bar and starts keeping your clipboard right away.

    Upgrading from an older build and using auto-paste? Remove Stash under System Settings → Privacy & Security → Accessibility and add it back.

  3. 03

    Press ⌘ ⇧ V

FAQ

Questions answered

Is it really free?

Yes. No account, no subscription, no trial that ends. Download it and it works.

Does anything I copy get uploaded?

No. Ordinary history lives in memory and clears when you quit. The clips you pin and the prompts you save go to a single file on your own machine — on macOS that's ~/Library/Application Support/Stash/, on Windows %APPDATA%\Stash\. Nothing is sent anywhere.

What happens if I copy a password or an API key?

Stash detects common secret shapes — keys with known prefixes, JWTs, AWS credentials, high-entropy tokens, 2FA codes and Luhn-valid card numbers — and skips them silently. They're never added to history and never written anywhere.

It's tuned to avoid false positives, but no heuristic is perfect. Treat Stash as a session tool, not a vault; anything genuinely sensitive still belongs in a password manager.

Why does Windows warn me on first launch?

The Windows build isn't code-signed yet, so SmartScreen interrupts the first run. Click More info, then Run anyway. The Mac builds are signed and notarized by Apple, so they open with no warning at all.

How many clips does it keep?

The last 100 of ordinary history. Pinned clips, prompts and anything in a session don't count toward that cap and don't age out — marking something is what makes it permanent.

Does text extraction work offline?

Yes. It uses the operating system's own engine — Apple's Vision framework on macOS, Windows OCR on Windows — so nothing is sent to a server. It does mean the feature needs macOS or Windows; there's no bundled fallback.

How do updates work?

Stash checks at startup and every six hours, downloads in the background while you work, and swaps the new version in when you restart. Nothing is installed without you restarting.

Can I stop it recording for a while?

Yes. Toggle the live indicator in the titlebar, or use the tray menu. Anything copied while paused stays ignored after you resume.
